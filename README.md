# c__math

## 中文说明

一个使用 C++ 编写的数学工具与算法练习项目。

### 包含内容

- 四则基本运算：`four basic arithmetic operations.h`
- 最大公约数与最小公倍数：`gcd_lcm.h`

### 环境要求

- 支持 C++ 的编译器，例如 GCC、G++ 或 MSVC

### 使用方法

在 C++ 文件中引用所需头文件：

```cpp
#include "gcd_lcm.h"
```

如果已有 `main.cpp`，可使用 G++ 编译：

```bash
g++ main.cpp -o c__math
./c__math
```

## English

A C++ project containing mathematical tools and algorithm examples.

### Included

- Basic arithmetic operations: `four basic arithmetic operations.h`
- Greatest common divisor and least common multiple: `gcd_lcm.h`

### Requirements

- A C++ compiler such as GCC, G++, or MSVC

### Usage

Include the required header in a C++ source file:

```cpp

```

If you have a `main.cpp`, compile it with G++:

```bash

./c__math
```
